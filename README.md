# Assignment-01 - TuteDude HTML Learning Demo

This project is based on the TuteDude HTML Learning assignment.

## Included HTML concepts
- Semantic elements: header, main, section, article, aside, footer
- Heading with mark
- strong, em, abbr, time, blockquote, cite
- Navigation links
- figure and figcaption
- Complex table with thead, tbody and tfoot
- Nested nutrition tables
- details and summary
- audio and video elements
- Feedback form with fieldset, legend, inputs, select and textarea
- address and copyright time element

## Run
Open `index.html` directly in a browser.
